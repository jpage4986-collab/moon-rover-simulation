# 底座实体按钮

底座按钮通过 USB HID 输入设备由 Unity 读取，配置位于 `Assets (2)/Assets/Driver/ManualDriverWithAEB.cs`。

| 底座按钮显示编号 | 功能 |
|---|---|
| 1 | 在方向盘驾驶与手柄驾驶之间切换 |
| 11 | 切换车辆前灯 |

底座控制器在当前 Windows 输入设备顺序中为 Unity 摇杆 4。按钮编号按检测程序显示的实体编号设置，Unity 输入索引从 0 开始，因此实体按钮 1 对应索引 0，实体按钮 11 对应索引 10。

方向盘主控由方向盘上的 Bottom 3 按钮选择。主控方向盘的左拨片选择后退档，右拨片选择前进档；另一只方向盘使用力反馈跟随主控。
